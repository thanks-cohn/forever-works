# Dependency classifications

* **LOCKED**: implementation identity is contractual; replacement needs an explicit decision.
* **SEMANTIC**: implementation may change only with externally observable equivalence.
* **CAPABILITY**: any mechanism satisfying capabilities, constraints, and invariants is acceptable.
* **TRANSITIONAL**: deliberately temporary and requires a revisit condition.
* **LEGACY**: retained solely for historical compatibility.
* **OPTIONAL**: supports a nonessential feature removable through an intentional feature decision.
