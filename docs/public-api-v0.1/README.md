# Public API v0.1 Initiative

This directory contains the design and implementation material for the first stable public semantic API of Forever Works.

The initiative exists to make Forever Works usable by unfamiliar developers and future agents without making any one language, runtime, CLI, transport, vendor, or agent implementation canonical.

## Documents

- [PROPOSAL.md](PROPOSAL.md) — architecture, goals, scope, and adoption rationale.
- [CODEX_REQUEST.md](CODEX_REQUEST.md) — the approximately 30-minute implementation request.
- `../API/PUBLIC_API_V0_1.md` — to be created/maintained by the implementation run as the official API contract.
- `CODEX_HANDOFF_PUBLIC_API.md` — to be created by the implementation run as the continuation handoff.

The governing principle is:

> **Standardize semantics before transports.**

## Official API documentation

The permanent public API documentation lives in [`docs/API/`](../API/). This initiative directory remains the planning, implementation-request, and handoff workspace for Public API v0.1.
