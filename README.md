# Forever Works

**A longevity standard for software in the agentic era.**

Forever Works is a framework, specification, and tooling initiative for making software easier to preserve, understand, modernize, and safely evolve over long periods of time.

Its central premise is simple:

> **Software should carry forward not only its implementation, but also the intent, constraints, capabilities, and reasoning that made the implementation correct.**

A future agent should be able to inspect a project, understand why it was built the way it was, determine what must remain true, identify what may safely change, and modernize obsolete implementation details without erasing the project's original purpose.

Forever Works is designed to be language-, framework-, runtime-, and vendor-agnostic.

The foundational proposal is in:

- `docs/FOUNDATIONAL_PROPOSAL.md`

The repository name is not intended to constrain the eventual standard or package naming.
