# Conformance suite

`fixtures/cases.json` defines portable cases. A case is valid when semantic validation has no errors. Old `0.x` minor versions remain readable. `complete` contains replacement, compatibility, provenance, and preserving migration examples; `migration-violating` changes the protected invariant claim to fail. Golden normalized and evaluation files are generated by `scripts/update_goldens.py` and compared independently by the cross-conformance runner.
